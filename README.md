# Blackjack Project 🃏

Capstone Blackjack game built as part of Angela Yu’s 100 Days of Python Bootcamp.

## 📌 Features
- Play against a computer dealer.
- Implements standard Blackjack rules.
- Includes Ace (11 or 1) logic.
- ASCII art for visual fun.
- Looping gameplay with replay option.

## 🧠 What I Learned
- Python functions, conditionals, and loops
- List manipulation
- Score evaluation logic
- Modular structure (`main.py`, `art.py`)
